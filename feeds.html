API Documentation

Endpoints

Admin Feed Management

Path: /portfolio/feeds/admin/

Methods: GET, POST, PUT, DELETE

Description: Manage the feed, including retrieving all feeds, creating a new feed, updating an existing feed, and deleting a feed.

Publish Feed

Path: /portfolio/feeds/publish/

Method: POST

Description: Publish a feed by changing its status to 'published'.

Unpublish Feed

Path: /portfolio/feeds/unpublish/

Method: POST

Description: Unpublish a feed by changing its status to 'unpublished'.

Feed Categories

Path: /portfolio/feeds/category/

Method: GET

Description: Retrieve all feed categories.

Subscribe to Category

Path: /portfolio/feeds/subscribe/

Method: POST

Description: Subscribe to a feed category.

Unsubscribe from Category

Path: /portfolio/feeds/unsubscribe/

Method: POST

Description: Unsubscribe from a feed category.

User Dashboard Feeds

Path: /portfolio/feeds/users/

Method: GET

Description: Retrieve all feeds for the categories the user is subscribed to.

Feed Reactions

Path: /portfolio/feeds/reactions/<str:feed_id>/

Method: POST

Description: React to a feed with various types of reactions (agree, disagree, like, trading, monitoring).

Views

FeedView

Description: Manage feeds for the admin.

GET

Retrieve all feeds.

Response: Serialized feed data.

POST

Create a new feed.

Request:

  • topic: Topic of the feed.
  • title: Title of the feed.
  • image: Image for the feed.
  • content: Content of the feed.
  • category: Category of the feed.
  • image_caption: Caption for the image.
  • symbol: Symbol related to the feed.
  • subtitle: Subtitle of the feed.

Response: Serialized feed data.

PUT

Update an existing feed.

Request: Updated feed data.

Response: Serialized feed data or validation errors.

DELETE

Delete a feed.

Request: Feed ID.

Response: Status code 204 No Content.

PublishFeed

Description: Publish a feed.

POST

Request: Feed ID.

Response: Status code 200 OK.

UnpublishFeed

Description: Unpublish a feed.

POST

Request: Feed ID.

Response: Status code 200 OK.

FeedCategoryView

Description: Retrieve all feed categories.

GET

Response: Serialized category data.

SubscribeCategoryAPIView

Description: Subscribe to a feed category.

POST

Request: Category name.

Response: Success or error message.

UnsubscribeCategoryAPIView

Description: Unsubscribe from a feed category.

POST

Request: Category name.

Response: Success or error message.

UserDashboardFeedsAPIView

Description: Retrieve all feeds for the categories the user is subscribed to.

GET

Response: Serialized feed data.

DashboardFeedReactionAPIView

Description: React to a feed.

POST

Request:

  • feed_id: ID of the feed to react to.
  • agree: Agree reaction (boolean).
  • disagree: Disagree reaction (boolean).
  • like: Like reaction (boolean).
  • trading: Trading reaction (boolean).
  • monitoring: Monitoring reaction (boolean).

Response: Success message.

Serializers

DashboardFeedSerializer

Model: DashboardFeed

Fields: All fields of the DashboardFeed model.

Custom Representation: Includes aggregated counts for each reaction type (agree, disagree, like, trading, monitoring).
