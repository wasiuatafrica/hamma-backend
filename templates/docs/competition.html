API Documentation

URLs

/competition/competition/

       "end_date": "2023-08-31T23:59:59Z",
       "title": "Summer Trading Competition",
       "created_at": "2023-07-15T12:00:00Z",
       "status": "current",
       "first_prize": "1000000",
       "second_prize": "500000",
       "third_prize": "250000",
       "message": "Join our summer trading competition and win big!"
   },
   {
       "id": 2,
       "start_date": "2023-03-01T00:00:00Z",
       "end_date": "2023-03-31T23:59:59Z",
       "title": "March Madness Trading Competition",
       "created_at": "2023-02-15T12:00:00Z",
       "status": "closed",
       "first_prize": "750",
       "second_prize": "400",
       "third_prize": "150",
       "message": "Participate in our March Madness trading competition!"

  • Method: POST

    Creates a new competition. If there is an ongoing competition, it marks it as closed before creating the new one.

    Sample Payload:

{
   "start_date": "2023-09-01T00:00:00Z",
   "end_date": "2023-09-30T23:59:59Z",
   "title": "Fall Trading Competition",
   "first_prize": "1200",
   "second_prize": "800",
   "third_prize": "400",
   "message": "Join our fall trading competition and win big!"
}

/competition/join-leave/{competition_id}/{action}/

  • Method: POST

    Allows the user to join or leave a competition.

    • competition_id is the ID of the competition.
    • action can be either join or leave.
    Sample Response (on successful join):

{
   "detail": "You have successfully joined this competition"
}
    Sample Response (on successful leave):

{
   "detail": "You have successfully left this competition"
}

/competition/wallet/

  • Method: GET

    Returns the user's wallet balance, including deposited amount, invested amount, uninvested amount, balance, and reserve.

    Sample Response:

{
   "deposited": 1000000,
   "invested": 500000,
   "uninvested": 500000,
   "balance": 500000,
   "reserve": 500000
}

/competition/check/

  • Method: GET

    Checks if the user is currently participating in an active competition.

    Sample Response (if participating):

{
   "competition": "True",
   "status": "active"
}
    Sample Response (if not participating):

{
   "competition": "False",
   "status": "inactive"
}

/competition/trading-days/

  • Method: GET

    Returns a list of trading days for the user in the current competition.

    Sample Response:

{
   "trading_days": [
       "2023-08-01",
       "2023-08-03",
       "2023-08-05",
       "2023-08-10"
   ]
}

/leaderboard/

  • Method: GET

    Returns the leaderboard for the current competition, sorted by total profit.

    Sample Response:

[
   {
       "user": "John Doe",
       "total_profit": 50000,
       "percentage_profit_24_hours": 2.5,
       "percentage_profit_1_week": 10.0
   },
]
