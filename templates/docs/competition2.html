API Documentation

URLs

/leaderboard/join-leave/{competition_id}/{action}/

  • Method: POST

    Allows the user to join or leave a competition.

    • competition_id is the ID of the competition.
    • action can be either join or leave.
    Sample Response (on successful join):

{
   "detail": "You have successfully joined this competition"
}
    Sample Response (on successful leave):

{
   "detail": "You have successfully left this competition"
}

/leaderboard/check/

  • Method: GET

    Checks if the user is currently participating in an active competition.

    Sample Response (if participating):

{
   "competition": "True",
   "status": "active"
}
    Sample Response (if not participating):

{
   "competition": "False",
   "status": "inactive"
}

/leaderbaord/trading-days/

  • Method: GET

    Returns a list of trading days for the user in the current competition.

    Sample Response:

{
   "trading_days": [
       "2023-08-01",
       "2023-08-03",
       "2023-08-05",
       "2023-08-10"
   ]
}
