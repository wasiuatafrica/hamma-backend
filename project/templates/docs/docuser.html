1. Registration

1a. Signup

POST /auth/register/

Request Body:
    {
        "email": "user@example.com",
        "firstname": "John",
        "lastname": "Doe",
        "password": "your_password",
        "ref_code": "optional_referral_code"
    }
Response:
Success Response (201 Created):
    {
        "detail": "A token has been sent to your mail",
        "user": {
            "id": 1,
            "email": "user@example.com",
            "firstname": "John",
            "lastname": "Doe",
            "has_2fa": false,
            "twofa_type": null,
            "is_active": true,
            "totp_url": null,
            "date_joined": "2023-12-05T12:34:56.789Z",
            "last_login": null
        }
    }
Error Response (400 Bad Request):
    {
        "email": ["This field is required."],
        "password": ["This field is required."],
        "firstname": ["This field is required."],
        "lastname": ["This field is required."]
    }
1b. Verify Email

POST /auth/verify_token/

Request Body:
    {
        "user_email": "user@example.com",
        "token": "your_token"
    }
Response:
Success Response (200 ok):
    {
        "detail": "Account verified.",
        
    }
Error Response (400 Bad Request):
    {
        "detail": "Token or user_email missing"
    }

2. Login

2a. Login

POST /auth/login/

Request Body:
    {
        "email": "user@example.com",
        "password": "your_password"
    }
Response:
Success Response (200 OK):
    {
        "detail": "Please provide token from your 2fa application"
    }
Success Response (202 Accepted):
    {
        "detail": "Please check your mail for your 2fa token"
    }
Error Response (404 Not Found):
    {
        "detail": "This account does not exist"
    }
Error Response (400 Bad Request):
    {
        "detail": "This account is not active. Please verify account before login."
    }

2b. Verify Login Token

POST /auth/login-with-2fa/

Request:

Send a POST request to perform the second stage of the login process (after receiving the 2FA token).

Request Body:

    {
        "email": "user@example.com",
        "token": "your_token"
    }

Response:

Status Codes:

  • 200 OK - Successful login
  • 401 Unauthorized - Invalid token
  • 404 Not Found - User not found or inactive account

Success Response (200 OK):

    {
        "refresh": "your_refresh_token",
        "access": "your_access_token",
        "user": {
            "id": 1,
            "email": "user@example.com",
            "firstname": "John",
            "lastname": "Doe",
            "has_2fa": true,
            "twofa_type": "authapps",
            "is_active": true,
            "totp_url": "your_totp_url",
            "date_joined": "2023-12-05T12:34:56.789Z",
            "last_login": "2023-12-05T12:34:56.789Z"
        }
    }

Error Response (401 Unauthorized):

    {
        "detail": "Invalid token"
    }

Error Response (404 Not Found):

    {
        "detail": "User not found or user account not active"
    }

4. Reset Forgotten Password

4a. Request Reset Token

POST /reset-password/

Request Body:
    {
        "email": "user@example.com"
    }
Response:
Success Response (200 OK):
    {
        "detail": "Reset password token has been sent to your email. Token will expire in 10 mins"
    }
Error Response (404 Not Found):
    {
        "detail": "User not found or invalid email"
    }

4b. Validate Reset Token

GET /reset-password/

Request Parameters:
    {
        "email": "user@example.com",
        "token": "reset_token"
    }
Response:
Success Response (200 OK):
    {
        "detail": "Ok"
    }
Error Response (400 Bad Request):
    {
        "detail": "email and token are required"
    }
Error Response (401 Unauthorized):
    {
        "detail": "Invalid token"
    }

4c. Update Password with Token

PUT /reset-password/

Request Body:
    {
        "email": "user@example.com",
        "token": "reset_token",
        "new_password1": "new_password",
        "new_password2": "new_password"
    }
Response:
Success Response (200 OK):
    {
        "detail": "Password updated successfully"
    }
Error Response (404 Not Found):
    {
        "detail": "User with this email not found."
    }
Error Response (401 Unauthorized):
    {
        "detail": "Invalid token"
    }
Error Response (400 Bad Request):
    {
        "detail": "new_password1 and new_password2 must match"
    }

4d. Update Password from Dashboard

POST /update-password-dashboard/

Request Body:
    {
        "current_password": "current_password",
        "new_password1": "new_password",
        "new_password2": "new_password"
    }
Response:
Success Response (200 OK):
    {
        "detail": "Password updated successfully"
    }
Error Response (400 Bad Request):
    {
        "detail": "new_password1 and new_password2 must match"
    }
Error Response (400 Bad Request):
    {
        "detail": "current_password is wrong"
    }
