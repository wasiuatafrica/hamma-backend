GET /anyon/receipts/

Response:
              Use this endpoint to retrieve a list of uploaded receipts.
              {
                  "id": 1,
                  "user": 1,
                  "fullname": "John Doe",
                  "amount": 100.00,
                  "payment_method": "Bank Transfer",

2b. Approve/Reject Receipt

POST /anyon/receipts/

Request Body:

              {
                  "id": 1,
                  "amount": 100.00,
                  "receipt_status": "approved",
                  "comment": "Optional rejection comment"
              }
Response:
Success Response (200 OK):
  {
      "id": 1,
      "user": 1,
      "fullname": "John Doe",
      "amount": 100.00,
      "payment_method": "Bank Transfer",
      "receipt_status": "approved",
      "comment": "Receipt comment",
      "created": "2023-12-05T12:34:56.789Z",
      "approved_date": "2023-12-05T12:34:56.789Z",
      "image_url": "/media/Receipts/receipt_image.jpg"
  }
Error Response (400 Bad Request):
  {
      "receipt_status": ["receipt_status must either be approved or rejected"]
  }

3. Approve/Reject Withdrawals

3a. Get Withdrawal Requests

GET /withdrawals/

Response:
            Use this endpoint to retrieve a list of withdrawal requests.
            {
                "id": 1,
                "fullname": "John Doe",
                "user_id": 1,
                "amount": 100.00,
                "status": "Pending",
                "created": "2023-12-05T12:34:56.789Z"
            }

3b. Approve/Reject Withdrawal

POST /withdrawals/

Request Body:
            Use the following JSON payload to approve or reject a withdrawal:
            {
                "id": 1,
                "action": "approved"  # or "rejected"
            }
Response:
Success Response (200 OK):
{
    "id": 1,
    "fullname": "John Doe",
    "user_id": 1,
    "amount": 100.00,
    "status": "approved",
    "created": "2023-12-05T12:34:56.789Z"
}
Error Response (400 Bad Request):
{
    "action": ["action must be approved or rejected"]
}
Error Response (403 Forbidden):
{
    "detail": "Insufficient fund"
}

4. User Management

4a. Get Users

GET /anyon/manage-users/

Request Parameters:
          Use the following query parameters to filter users:
          {
              "email": "user@example.com"
          }
Response:
          Use this endpoint to retrieve a list of users or details of a specific user.
          {
              "id": 1,
              "email": "user@example.com",
              "firstname": "John",
              "lastname": "Doe",
              "has_2fa": false,
              "twofa_type": null,
              "is_active": true,
              "date_joined": "2023-12-05T12:34:56.789Z",
              "last_login": null
          }
Scenarios:
  • 1. Fetch All Users: Make a GET request to /manage-users/ without any query parameters.
  • 2. Fetch Single User by Email: Include "email" query parameter to get details of a specific user.
  • 3. Fetch Single User by ID: Include "user_id" in the URL to get details of a specific user.
Examples:

1. Fetch All Users: GET /manage-users/

2. Fetch Single User by Email: GET /manage-users/?email=user@example.com

3. Fetch Single User by ID: GET /manage-users/1/

4b. Update User Details

PUT /anyon/manage-users/{user_id}/

Request Body:
          Use the following JSON payload to update user details:
          {
              "email": "user@example.com",
              "firstname": "John",
              "lastname": "Doe",
              "is_active": true
          }
Response:
Success Response (200 OK):
{
  "id": 1,
  "email": "user@example.com",
  "firstname": "John",
  "lastname": "Doe",
  "has_2fa": false,
  "twofa_type": null,
  "is_active": true,
  "date_joined": "2023-12-05T12:34:56.789Z",
  "last_login": null
}
Error Response (400 Bad Request):
{
  "email": ["This field is required."]
}

4c. Delete User

DELETE /anyon/manage-users/{user_id}/

Response:
{
  "detail": "User deleted successfully"
}
